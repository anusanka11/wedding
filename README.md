# Avishka & Anush — Wedding Invitation

A responsive, mobile-first wedding invitation webpage.

## Included
- Premium responsive HTML/CSS/JavaScript UI
- Uploaded wedding artwork and bride illustration
- Four replaceable pre-shoot photo placeholders
- Wedding timeline
- Google Maps location button
- WhatsApp RSVP button to 0714943887
- Add-to-calendar `.ics` download
- PWA manifest + service worker for supported hosting
- Works on phones, tablets and desktops

## Replace pre-shoot photos
Open `assets/` and replace:
- `Pre shoot1.jpg`
- `Pre shoot2.jpg`
- `Pre shoot3.jpg`
- `Pre shoot4.jpg`

Keep the filenames exactly the same.

## Publish online
Upload the contents of this folder to any static web host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or your own hosting.

The invitation is already responsive, so the same link can be opened on mobile, tablet or PC.
